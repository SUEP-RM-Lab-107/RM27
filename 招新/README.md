# 招新后续计划

## 一、目前存在的问题

由于目前招新人数持续流失，同时有较多新生反映学习内容存在一定难度，因此希望大家能够一起集思广益，讨论后续的培养计划，思考新生究竟需要学习哪些知识，以及如何合理安排学习进度。

## 二、后续学习计划

1. **大作业延期**

2. **C 语言入门**
   - 预计用时：**1 个月**
   - 主要用于学习和练习 C 语言基础语法，巩固编程基础。

3. **C++ 与 CMake 强化**
   - 在掌握 C 语言基础后，进一步强化 C++ 编程能力及 CMake 项目构建能力。

4. **Vibe Coding**
   - 建议放在整个学习计划的最后阶段进行。
   - 我个人认为，应该先建立扎实的编程基础，再接触 AI 辅助编程。

5. **电脑基础知识穿插教学**
   - 将电脑基础知识融入日常教学，在学习编程的过程中穿插讲解。

## 三、关于 AI 的使用态度

**不希望新生直接使用 AI Agent 完成作业。**

AI 可以作为辅助学习的工具，例如：

- 帮助分析问题，提供思路。
- 告诉你接下来可以分几步完成任务。
- 解释不理解的知识点和技术概念。

但不应该将整个任务完全交给 AI Agent 代为完成。

**我们希望大家能够借助 AI 提高学习效率，而不是让 AI 代替自己学习和思考。**

如果将作业完全托付给 AI，就违背了学习的初衷。

## 四、征求大家的意见

欢迎大家提出建议，共同完善后续的招新培养计划。
